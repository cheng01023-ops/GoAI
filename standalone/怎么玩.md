# GoBoard 9x9 —— 双击就能下围棋（AI 已经编译在程序里）

## 最快开始

| 你的系统 | 双击这个 | 说明 |
|---|---|---|
| Windows | `PLAY_NOW.bat` | 用包里的 `GoBoard.exe` + 最强权重 `weights/goai9x9_v5_800sims.bin`，**不需要编译器** |
| macOS（Apple 芯片） | `PLAY_macOS.command` | 用包里的预编译版 `GoBoard-macOS`，**不需要编译器** |
| macOS（Intel）/ Linux | `PLAY_macOS.command` | 会自动从源码编译（macOS 先跑 `xcode-select --install`） |
| Windows（想连代码一起更新） | `BUILD_AND_PLAY.bat` | 用 w64devkit 的 gcc 重新编译（源码里已是最强权重） |

## ⚠️ Windows 上打不开？先看这里（这个包已经修好了）

之前发出去的 Windows 包有两个问题，这个包全部修复：

| 症状 | 原因 | 现在 |
|---|---|---|
| 双击 `PLAY_NOW.bat` 没反应 / 一闪而过 / 报语法错 | 那个 .bat 是 **Unix 行尾**，而且 `chcp 65001` **之前**写了中文 —— 中文 Windows 的 cmd（cp936）会按 GBK 误解码，解析直接崩 | 已改：**CRLF 行尾** + `chcp` 之前**全 ASCII** + 用 `goto` 标签（不再用易碎的多行 `if (...)` 块） |
| 下起来感觉不强 | 包里的 `GoBoard.exe` 是旧版，**内置的是 v3 权重** | 已换成**内置 v5（最强）**的重编译版；`PLAY_NOW.bat` 还会显式加载 `weights/goai9x9_v5_800sims.bin`，两条路都指向最强 AI |

还是起不来怎么办：

- **报缺少 `libwinpthread-1.dll`** → `PLAY_NOW.bat` 会自动切换到备用版
  `GoBoard-fallback.exe`（不依赖额外 DLL，加载同一份 v5 权重）。
  或者直接双击 `BUILD_AND_PLAY.bat` 在本机重编译 —— 现在的编译命令带 `-static`，产物不再依赖额外 DLL。
- **想确认用的是哪份权重** → 启动后界面顶部会显示 `内置权重(32ch)`；用 `--weights` 指定文件时状态栏显示文件名。
- **不想下棋只想验证程序能跑** → 命令行执行 `GoBoard.exe --selftest --sims 60`（AI 自己下 40 手）。

## 这是什么 AI

- 9 路棋盘，32 通道卷积网络，每步 **800 次 MCTS 模拟**
- 自我对弈训练 **27,800 局**（v5，目前最强存档；对上一代 v4 实测 81.7%）
- 权重**直接编译进程序**：单个可执行文件就是完整 AI，不需要额外的模型文件

想换强度 / 颜色：

    --sims 400           每步搜索 400 次（更强更慢）
    --white              你执白，AI 先行
    --handicap 2         让 2 子
    --weights 文件.bin   换成别的权重（例如 weights/goai9x9_v3_33kgames.bin 会弱一些）

## 按键

全屏界面：**方向键 / hjkl** 移动光标 · **回车** 落子 · `p` 停着 ·
`u` 悔棋 · `i` 提示 · `s` 存棋谱 · `n` 新局 · `r` 认输 · `q` 退出。
纯文本界面：直接输入坐标（如 `D4`）。

## 想改代码

| 文件 | 作用 |
|---|---|
| `src/goboard.c` | 人机对弈界面（全屏 / 文本两套） |

`gcc -O3 -std=c11 -DGOAI_NO_CURSES -Iinclude src\goboard.c src\board.c src\compat.c src\net.c src\mcts.c -o GoBoard.exe -lm`
